프론트엔드 디버깅 체크리스트

  1. HTML 구조 및 콘텐츠
   - 시맨틱 태그 유효성: header, nav, section, footer 등의 시맨틱 태그가
     의미에 맞게 올바르게 사용되었는지 확인합니다.
   - `onclick` 속성: HTML에 직접 작성된 onclick 이벤트 핸들러가
     많습니다. 이 함수들이 script.js 또는 index.html 내의 스크립트      
     태그에 모두 정의되어 있는지, 오타는 없는지 확인합니다.
   - ID 및 클래스 중복/오타: JavaScript에서 사용하는 ID(productModal,   
     inquiryForm 등)가 중복되지 않고, 오타 없이 정확하게 사용되었는지   
     확인합니다.
   - 이미지 경로: images/ 폴더의 모든 이미지 파일(<img> 태그 및 CSS     
     background-image) 경로가 올바르고, 이미지가 정상적으로 로드되는지  
     확인합니다. 깨진 이미지가 없는지 검사합니다.

  2. CSS 및 반응형 디자인
   - 레이아웃 깨짐 현상:
       - 특히 Flexbox와 Grid(form-grid, product-grid)가 복잡하게 사용된 
         부분에서 특정 브라우저나 화면 크기에서 레이아웃이 깨지는지     
         확인합니다.
       - position: absolute/fixed를 사용하는 팝업(msds-popup),
         모달(productModal), 모바일 메뉴(mobile-menu)가 다른 요소에 의해
         가려지거나, 스크롤 시 위치가 어긋나는지 확인합니다.
   - 반응형 디자인:
       - @media (max-width: 768px) 등 미디어 쿼리 분기점에서 디자인이   
         의도대로 변경되는지 브라우저 크기를 조절하며 테스트합니다.     
       - 모바일 화면에서 데스크탑용 내비게이션(nav.nav)이 숨겨지고      
         햄버거 버튼이 나타나는지 확인합니다.
       - 모바일 메뉴(mobile-menu)가 정상적으로 열리고 닫히는지, 메뉴 내 
         아코디언 기능(toggleMobileSubmenu)이 올바르게 작동하는지       
         확인합니다.
   - `!important` 사용: CSS에 !important 규칙이 여러 개 있습니다. 이로  
     인해 다른 스타일이 예기치 않게 덮어쓰이는 문제가 발생할 수
     있으므로, 스타일 충돌이 의심될 때 이 부분을 우선적으로 확인합니다. 

  3. 핵심 JavaScript 기능 (UI 상호작용)
   - 페이지 탐색 (`navigateTo`):
       - 상단 및 하단 메뉴 클릭 시 navigateTo 함수가 호출되어 해당      
         섹션으로 부드럽게 스크롤되는지 확인합니다.
       - navigateTo 호출 시 의도하지 않은 화면 깜빡임이나 이동 오류가   
         없는지 확인합니다.
   - 히어로 캐러셀:
       - nextSlide, prevSlide 버튼과 하단 점(dot)들이 정상 작동하는지   
         확인합니다.
       - 5초 간격의 자동 슬라이드 기능(startAutoSlide)이 올바르게       
         동작하고, 수동 조작 시 타이머가 초기화되는지 확인합니다.       
   - 모달 및 팝업:
       - 제품 카드 클릭 시 showProductDetail 함수가 상품 정보를 가지고  
         모달을 정상적으로 띄우는지 확인합니다.
       - 페이지 로드 2초 후 showMsdsPopup 함수가 MSDS 안내 팝업을       
         보여주는지, 닫기 버튼/오버레이 클릭 시 closeMsdsPopup이 정상   
         작동하는지 확인합니다.
   - 카카오맵 렌더링:
       - renderKakaoMap 함수가 '회사소개' 섹션이 활성화될 때 지도를     
         올바르게 렌더링하는지 확인합니다. 초기 로드 시 또는 다른 섹션에
         있다가 '회사소개'로 이동했을 때 지도가 깨지지 않는지
         확인합니다.
   - 다국어 (`toggleLanguage`): 'ENG'/'KOR' 버튼 클릭 시 메뉴 등의      
     텍스트가 정상적으로 변경되는지 확인합니다.

  4. 문의 시스템 (Asynchronous JavaScript)
   - 문의 등록 (`submit-inquiry`):
       - 필수 입력 필드(성명, 이메일, 내용, 비밀번호) 유효성 검사가 잘  
         작동하는지 확인합니다.
       - '문의 등록하기' 버튼 클릭 시 fetch API를 통해 /submit-inquiry  
         함수로 데이터가 정상적으로 전송되는지 브라우저 개발자
         도구(F12)의 'Network' 탭에서 확인합니다.
       - 등록 성공/실패 시 showStatus 함수가 적절한 메시지("✓ 문의가    
         등록되었습니다" 또는 에러 메시지)를 보여주는지 확인합니다.     
       - 등록 처리 중 버튼이 비활성화되고 "처리중..." 텍스트로
         변경되는지 확인합니다.
   - 공개 문의 목록 (`get-public-list`):
       - 페이지 로드 시 /get-public-list API를 호출하여 목록을
         성공적으로 가져오는지 확인합니다.
       - '더보기' 버튼이 5개 이상의 항목이 있을 때만 나타나고, 클릭 시  
         5개씩 목록을 추가로 보여주는지 확인합니다.
       - 등록된 문의가 없을 때 "등록된 문의가 없습니다" 메시지가        
         표시되는지 확인합니다.
   - 문의 상세 확인:
       - 목록의 특정 행 클릭 시 toggleInquiryDetail 함수가 비밀번호를   
         입력할 수 있는 상세 정보 창을 아코디언처럼 열어주는지
         확인합니다.
       - 비밀번호 입력 후 '확인' 버튼 클릭 시 /verify-password와        
         /get-inquiry-detail API가 순차적으로 호출되는지 'Network'      
         탭에서 확인합니다.
       - 비밀번호가 틀렸을 때 에러 메시지를 표시하고, 맞았을 때 상세    
         내용과 관리자 답변을 올바르게 렌더링하는지 확인합니다.
  5. 성능 및 최적화
   - 이미지 크기: images 폴더의 배경 이미지나 상품 이미지가 웹에 비해
     너무 크지 않은지 확인합니다. (예: 수MB 크기의 PNG 파일)
   - 스크립트 실행 시점: window.addEventListener("load", ...)를 사용하여
     페이지의 모든 리소스(이미지 포함)가 로드된 후 스크립트를 실행하고
     있습니다. 이로 인해 기능 시작이 늦어질 수 있으므로,
     DOMContentLoaded 이벤트로 변경하여 더 빠른 상호작용이 가능한지
     검토할 수 있습니다.
   - API 응답 속도: Netlify 함수들의 응답 시간을 'Network' 탭에서
     확인합니다. 특정 함수가 너무 느리다면 백엔드 코드의 최적화가 필요할
     수 있습니다.
